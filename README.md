# Baim APK Builder

Ubah website jadi aplikasi Android (.apk) instan.

## Deploy ke Vercel

1. Clone repo ini
2. `npm install`
3. `vercel --prod`

Atau langsung deploy dengan tombol:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/username/baim-apk-builder)

## Cara pakai

1. Buka website Baim
2. Isi nama aplikasi dan URL website
3. Upload icon (opsional)
4. Klik "Build APK"
5. Tunggu beberapa detik, APK akan otomatis terunduh

## Teknologi

- Node.js + Express (backend)
- Jimp (resize icon)
- PWABuilder API (build APK)
